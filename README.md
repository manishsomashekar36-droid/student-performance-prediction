# Student Performance Prediction using Machine Learning

## 📌 Project Overview

This project uses Machine Learning to predict a student's final academic score based on study hours, attendance, previous marks, and assignment performance.

## 🎯 Objective

The main objective is to build a simple Machine Learning model that can estimate student performance using academic factors.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab
- GitHub

## 🤖 Machine Learning Model

The project uses Linear Regression to predict the final score.

### Input Features

- Study Hours
- Attendance
- Previous Marks
- Assignment Score

### Output

- Predicted Final Score

## 📊 Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## 🚀 How to Run

1. Open the Student_Performance_Prediction.ipynb notebook.
2. Open it using Google Colab.
3. Run the cells from top to bottom.
4. Enter the required student information.
5. View the predicted final score.
